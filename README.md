# Trang Chủ với Bootstrap

Bài thực hành theo nội dung CodeGym. Bootstrap 5.3.3 và Font Awesome 6.5.2.

## Chạy
Mở index.html; cần Internet để tải thư viện CDN.

## Đề bài
https://internship.codegym.vn/learning/18/activity/1546

## Kiểm tra
375, 768, 1440 px không tràn ngang; ảnh và font icon tải đúng. Carousel chuyển tới ảnh 2 và quay lại ảnh 1 bằng hai nút. 
Form liên hệ được thử bằng dữ liệu mẫu hợp lệ và hiển thị xác nhận kiểm tra trên trình duyệt.
